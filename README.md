# دليل عالم القهوة — The Complete Coffee Guide

كتاب عربي مصوَّر عن القهوة ومشروبات الكافيهات، من المبتدئ للمتقدم: أنواع البن، التحميص والمعالجة، عائلة الإسبريسو، طرق التحضير، الأدوات، الحليب والرغوة، وقاموس الباريستا.

**اقرأه أونلاين:** https://dobydragon.github.io/coffee-guide/

- `coffee_guide.pdf` — الكتاب كامل (PDF، A4)
- `coffee_guide_short.pdf` — نسخة مختصرة 10 صفحات

## الصور

الصور الفوتوغرافية من Wikimedia Commons و Unsplash برخصها الأصلية (CC0 / Public Domain / CC BY / CC BY-SA)، ومعدّلة بالقص وتغيير الحجم فقط. اسم المصوّر والرخصة مكتوبين تحت كل صورة، والقايمة الكاملة في [references.md](references.md).
